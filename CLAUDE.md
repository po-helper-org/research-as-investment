# Исследование идей: инструкция для Claude

Этот репозиторий — методология и инструменты для исследования идей, гипотез и рыночных направлений так, чтобы каждое исследование давало решение, переиспользуемое знание и новые гипотезы. Описание для людей — [README.md](README.md), методология — [METHODOLOGY.md](METHODOLOGY.md).

## Правила

@.claude/rules/research-and-knowledge.md

## Карта

| Путь | Назначение |
| --- | --- |
| `METHODOLOGY.md` | Методология: принципы, 8 шагов, уровни глубины L0–L4, уровни доказательства E0–E6 |
| `scoring/rubric.json` | Рубрика: критерии, веса, якоря, потолки без источника, порог |
| `scoring/score.py` | Score: взвешенное среднее геометрическое, потолки для критериев без источника |
| `scoring/sensitivity.py` | Ценность информации: вердикт kill / go / research и размах по критериям |
| `knowledge/` | База знаний: атомы-факты, паттерны, кладбище гипотез, открытые вопросы, журнал окупаемости |
| `dossiers/` | Досье исследований |
| `ideas.jsonl` | Идеи и развороты, появившиеся в исследованиях |
| `examples/` | Разобранные примеры |

## Скиллы

| Скилл | Когда использовать |
| --- | --- |
| `research-idea` | Исследовать видение, гипотезу или идею: от скрининга до досье и шага к покупателю |

## Как работать

- Любое исследование — по скиллу `research-idea` и правилу выше.
- Score не считай в уме: `python scoring/score.py <файл>` и `python scoring/sensitivity.py <файл>`.
- Отвечай на языке пользователя; файлы базы знаний пиши на одном языке, чтобы поиск по ним работал.
- Заканчивай работу следующим конкретным шагом к разговору с покупателем, если он есть.
