# Открытые вопросы

Вопросы, которые исследования не закрыли. Перед исследованием посмотри, не ответит ли оно на какой-то из них заодно. Ценность — насколько ответ может сменить решение по живым идеям: высокая, средняя, низкая. Закрытый вопрос не удаляется: статус меняется на «закрыт» со ссылкой на атом.
